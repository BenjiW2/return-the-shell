# Return the Shell

A scroll-through story of one oyster reef on Quandamooka Sea Country (Moreton Bay): how it was cared for, dredged away, and is being rebuilt.

Made as a science communication project for the Coastal Ecosystems course at the University of Queensland. We are not Quandamooka people and do not speak for Traditional Owners; everything about Quandamooka knowledge comes from the published sources listed at the end of the story.

## Run it

Open `index.html` in a browser. No build step.

- `index.html`: the story text and step settings
- `css/style.css`: layout and type
- `js/scene.js`: the illustrated tidal-flat scene (canvas)
- `js/app.js`: scroll engine, satellite map, slider and tabs
- `assets/`: the photographs and engravings the scene is built from, all public domain or CC0. Each one is credited under "Pictures" at the end of the story.

The satellite map (MapLibre with Esri World Imagery) and fonts load from the web. Offline, map steps fall back to the illustration.

Add `?still=13` (any step from 0 to 30) to the address to freeze the page on one step for screenshots.
